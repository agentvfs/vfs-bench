Help me organize and submit the February 2026 expense report.

## Tools

Each tool is a shell command; `<command> --help` says more.

- `finance list-transactions [--start-date <string>] [--end-date <string>]`: Get the list of expense transactions
- `finance get-transaction --transaction-id <string>`: Get details of a single transaction
- `finance submit-report --title <string> --transactions <value> ... --total-amount <number>`: Submit an expense report
