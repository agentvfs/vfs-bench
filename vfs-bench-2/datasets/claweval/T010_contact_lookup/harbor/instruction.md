Look up David Zhang's contact info in engineering.

## Tools

Each tool is a shell command; `<command> --help` says more.

- `contacts search --query <string> [--department <string>]`: Search for contacts by name
- `contacts get --contact-id <string>`: Get detailed contact information by ID
- `contacts send-message --contact-id <string> --message <string>`: Send a message to a contact
