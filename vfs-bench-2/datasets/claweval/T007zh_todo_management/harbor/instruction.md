帮我整理一下待办，重复的合并掉（请用标记完成的方式合并，不要删除任何待办项），过期的标记一下。

## Tools

Each tool is a shell command; `<command> --help` says more.

- `todo list-tasks [--status <string>]`: 获取所有待办事项
- `todo update-task --task-id <string> [--title <string>] [--priority <string>] [--status <string>] [--tags <value> ...]`: 更新待办事项
- `todo create-task --title <string> [--description <string>] [--priority <string>] [--due-date <string>]`: 创建新的待办事项
- `todo delete-task --task-id <string>`: 永久删除待办事项
